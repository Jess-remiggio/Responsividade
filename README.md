Este projeto foi desenvolvido com o objetivo de praticar e consolidar conceitos fundamentais de responsividade no desenvolvimento front-end, explorando como adaptar layouts para diferentes tamanhos de tela utilizando apenas HTML e CSS. A proposta foi transformar uma estrutura fixa em uma interface fluida, capaz de se ajustar de forma harmoniosa a dispositivos variados, como celulares, tablets e desktops, garantindo uma navegação confortável e uma experiência visual consistente. Durante o processo, trabalhei técnicas como uso de unidades relativas, organização de elementos em colunas e linhas flexíveis, ajustes de imagens, espaçamentos proporcionais e principalmente a aplicação de media queries para controlar o comportamento do layout em diferentes resoluções.

Ao longo do desenvolvimento, pude compreender melhor como cada elemento da página reage quando o espaço disponível muda, e como pequenas decisões de estilo podem impactar diretamente a usabilidade. A prática reforçou a importância de pensar o design de forma adaptativa desde o início, estruturando o HTML de maneira limpa e semântica, e aplicando o CSS de forma estratégica para garantir que o conteúdo permaneça legível e bem distribuído em qualquer dispositivo. Também exercitei a organização visual, o alinhamento dos componentes e a criação de uma hierarquia clara, permitindo que o usuário encontre facilmente as informações independentemente do tamanho da tela.

Este projeto representa um passo importante na minha evolução como desenvolvedora, pois me permitiu aplicar na prática os princípios essenciais da responsividade e entender como transformar um layout estático em uma interface flexível e moderna. Além de aprimorar minha técnica, reforçou minha autonomia e minha capacidade de construir páginas mais profissionais, acessíveis e preparadas para o uso real. É um exercício que contribui diretamente para minha formação e para a qualidade dos projetos que desenvolvo daqui em diante.
